# 🏫 Mapa Escolar Acessível

Este projeto apresenta um mapa interativo e acessível dos ambientes escolares, garantindo navegação simples, intuitiva e inclusiva para toda a comunidade.

## ♿ Boas Práticas de Acessibilidade Implementadas
1. **Identificação Dupla:** Cada ambiente é identificado por texto, ícone explicativo e cor (não dependendo exclusivamente das cores).
2. **Alto Contraste Visual:** Cores e textos com excelente contraste para facilitar a leitura por pessoas com baixa visão.
3. **Navegação por Teclado:** Foco visível (`outline`) e link de atalho `Pular para o conteúdo principal`.
4. **Design Responsivo:** Adaptável a dispositivos móveis (smartphones) e computadores desktop.
5. **Estrutura Semântica:** Utilização correta de tags HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).

## 🚀 Como publicar no GitHub Pages
1. Crie o repositório público no GitHub com os arquivos `index.html` e `style.css`.
2. Vá em **Settings** (Configurações) do repositório.
3. No menu lateral, acesse **Pages**.
4. Em **Build and deployment**, selecione a branch `main` (ou `master`) e salve.
5. Em instantes, o link público do seu site estará disponível!
